# Datos del Proyecto

Actualmente, el proyecto utilizará el dataset público **RAVDESS** (Ryerson Audio-Visual Database of Emotional Speech and Song) para el entrenamiento del modelo.

## Estructura de los datos
*   Videos en formato `.mp4`.
*   Emociones identificadas: Feliz, Triste, Ansioso, Neutral.

## Nota
Los videos no se suben al repositorio por su tamaño. Para ejecutar el código de extracción, se debe descargar el dataset por separado y colocarlo en esta carpeta.
